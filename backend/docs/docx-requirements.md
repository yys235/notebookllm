# Docx 编辑器 - 原始需求文档

## 一、功能概述

实现一个类似飞书文档的块级编辑器，作为 NotebookLLM 的新文档类型。

### 1.1 核心特性
- **块级编辑**: 所有内容都是独立的块，可自由移动、嵌套
- **斜杠命令**: 输入 `/` 快速插入各种内容块
- **Markdown 支持**: 支持 Markdown 语法快捷输入
- **丰富的块类型**: 支持标题、列表、代码、表格、媒体等

### 1.2 与现有 DocxEditor 的区别

| 特性 | 现有 DocxEditor | 新 Docx 类型 |
|------|-----------------|--------------|
| 编辑模式 | 连续文本流 | 块级编辑 |
| 命令系统 | 基础斜杠命令 | 完整命令体系 |
| 块操作 | 无 | 拖拽、多选、嵌套 |
| 数据格式 | HTML | JSON Block |
| 表格 | 基础 | 高级 (合并/排序) |

### 2.1 块类型 (P0 - MVP)

#### 文本块
| 块类型 | 标识 | 说明 |
|--------|------|------|

| 引用 | quote | 引用块 |
| 代码块 | code-block | 代码块，支持语法高亮 |

#### 列表块

| 有序列表 | ordered-list | 支持多级嵌套 |

| 块类型 | 标识 | 说明 |

| 块类型 | 标识 | 说明 |

### 2.2 斜杠命令系统

#### 命令分类

```
📝 基础
├── 标题 1        /h1, /heading1
├── 标题 2        /h2, /heading2
├── 标题 3        /h3, /heading3
├── 正文          /p, /paragraph
├── 引用          /quote, /blockquote
├── 代码块        /code, /codeblock
├── 分割线        /divider, /hr
└── 高亮块        /callout, /alert

📋 列表
├── 无序列表      /bullet, /ul
├── 有序列表      /ordered, /ol
├── 任务列表      /task, /todo
└── 折叠列表      /toggle, /collapse

🖼️ 媒体
├── 图片          /image, /img
├── 视频          /video
└── 文件          /file

📊 表格
├── 表格          /table
└── 插入行/列     (表格内)

🎨 样式
├── 分栏          /column, /grid
└── 书签          /bookmark

📅 插入
├── 日期          /date
├── 时间          /time
├── 表情          /emoji
└── 提及          /mention

#### 命令交互
- 输入 `/` 后立即显示命令菜单
- 支持模糊搜索: 输入 `cod` 匹配 `代码块`
- 键盘导航: ↑↓ 选择，Enter 确认，Esc 关闭
- 分类展示，带图标和描述

#### 行内格式
| 格式 | 快捷键 | Markdown |

| 加粗 | Ctrl+B | `**文字**` |

## 三、数据模型

### 3.1 文档结构

```typescript
interface DocxDocument {
  version: string           // 文档版本 "1.0"
  type: 'docx'             // 文档类型
  id: string               // 文档 ID
  blocks: Block[]          // 根级块列表
  metadata: {
    title?: string
    createdAt?: string
    updatedAt?: string
    author?: string
  }
}
```

### 3.2 块结构

```typescript
interface Block {
  id: string                    // 块 ID
  type: BlockType               // 块类型
  content?: string | TextElement[]  // 内容
  attrs?: BlockAttrs            // 块属性
  style?: BlockStyle            // 块样式
  children?: Block[]            // 子块
}

interface TextElement {
  type: 'text'
  text: string
  marks?: Mark[]                // 格式标记
}

interface Mark {
  type: MarkType
  attrs?: Record<string, any>
}

type BlockType =
  | 'paragraph' | 'heading1' | 'heading2' | 'heading3'
  | 'heading4' | 'heading5' | 'heading6'
  | 'quote' | 'code-block' | 'callout'
  | 'bullet-list' | 'ordered-list' | 'task-list' | 'toggle-list'
  | 'image' | 'video' | 'file'
  | 'divider' | 'table' | 'grid'

type MarkType =
  | 'bold' | 'italic' | 'underline' | 'strikethrough'
  | 'code' | 'link' | 'highlight'
  | 'textColor' | 'bgColor'
```

### 3.3 存储格式

```json
{
  "version": "1.0",
  "type": "docx",
  "id": "doc_xxx",
  "blocks": [
    {
      "id": "block_1",
      "type": "heading1",
      "content": [
        { "type": "text", "text": "欢迎使用 Docx 编辑器" }
      ]
    },
    {
      "id": "block_2",
      "type": "paragraph",
      "content": [
        { "type": "text", "text": "这是一个 " },
        { "type": "text", "text": "块级编辑器", "marks": [{ "type": "bold" }] },
        { "type": "text", "text": "。" }
      ]
    }
  ],
  "metadata": {
    "title": "示例文档",
    "createdAt": "2024-01-01T00:00:00Z"
  }
}
```
