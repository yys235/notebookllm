# 飞书文档 (Feishu Docx) 竞品分析报告

## 一、产品概述

### 1.1 产品定位
飞书文档是字节跳动旗下的在线协作文档工具，定位为"下一代办公协作平台"。核心特点是**块级编辑**、**实时协作**和**深度集成**。

### 1.2 目标用户
- 企业团队协作
- 项目管理
- 知识库建设
- 会议记录
- 个人笔记

---

## 二、核心功能分析

### 2.1 编辑架构 - 块级编辑 (Block-based)

飞书采用**块级编辑架构**，文档由多个"块"组成，每个块是独立的编辑单元。

#### 块类型清单

| 类别 | 块类型 | 说明 |
|------|--------|------|
| **文本** | 标题 H1-H6 | 支持层级、目录自动生成 |
| | 正文段落 | 支持富文本格式 |
| | 引用块 | 带样式的引用内容 |
| | 代码块 | 多语言语法高亮 |
| | 高亮块/提示框 | Callout，带图标和颜色 |
| **列表** | 无序列表 | 支持多级嵌套 |
| | 有序列表 | 支持多级嵌套 |
| | 任务列表 | 可勾选，支持进度统计 |
| | 折叠列表 | Toggle，可展开/收起 |
| **媒体** | 图片 | 上传/粘贴/拖拽/URL |
| | 视频 | 本地上传/嵌入链接 |
| | 音频 | 录音/上传 |
| | 文件 | 附件上传 |
| | 在线图片 | Unsplash/图标库 |
| **表格** | 表格 | 基础表格 |
| | 多维表格 | 类似 Notion Database |
| **智能** | 思维导图 | 内嵌脑图 |
| | 流程图 | 内嵌流程图 |
| | 画板 | 白板绘图 |
| | 公式 | LaTeX 数学公式 |
| **嵌入** | 网页嵌入 | iframe 嵌入 |
| | 文档链接 | 引用其他文档 |
| | 第三方 | B站、YouTube、Figma等 |
| **结构** | 分割线 | 水平线 |
| | 分栏 | 多列布局 |
| | 书签 | 网页书签卡片 |

### 2.5 块操作

#### 块菜单 (点击手柄)
```
[复制] [剪切] [删除]

[复制为Markdown]
[设为H1/H2/H3/正文]
[上移] [下移]
[复制链接]
```

#### 多选操作
- 鼠标拖选多个块
- Shift+点击连续选择
- Ctrl+点击不连续选择
- 批量删除、移动、设置属性

## 三、交互细节分析

### 3.1 输入体验

```
1. 光标定位 → 显示当前块的手柄
2. 输入 / → 弹出命令菜单
3. 选择命令 → 插入对应块
4. 输入 Markdown 语法 → 自动转换
5. 空行按 Backspace → 转为普通段落
```

### 3.2 选区体验

```
1. 选中文本 → 弹出浮动工具栏
2. 工具栏跟随选区位置
3. 点击外部 → 工具栏消失
4. 继续输入 → 保持格式
```

### 3.3 块交互

```
1. Hover 块 → 显示拖拽手柄
2. 点击手柄 → 显示块菜单
3. 拖拽手柄 → 可移动块
4. 长按手柄 → 多选模式
```

### 3.4 图片处理

```
1. 粘贴图片 → 自动上传
2. 拖拽图片 → 显示放置区域
3. 点击图片 → 显示工具栏 (大小/对齐/删除)
4. 支持拖拽调整大小
```

## 四、技术实现参考

### 4.1 数据结构 (JSON Block Model)

```typescript
interface Block {
  id: string                    // 唯一 ID
  type: BlockType               // 块类型
  content?: string | TextElement[]  // 内容
  attrs?: Record<string, any>   // 属性
  style?: BlockStyle            // 样式
  children?: Block[]            // 子块 (嵌套)
}

interface TextElement {
  type: 'text'
  text: string
  marks?: Mark[]                // 格式标记
}

interface Mark {
  type: 'bold' | 'italic' | 'underline' | ...
  attrs?: Record<string, any>
}
```

### 4.2 渲染架构

```
┌─────────────────────────────────────┐
│            Document View            │

│  Block Renderer (递归渲染块)         │

## 八、总结

飞书文档的核心优势在于：
1. **块级编辑** - 灵活的内容组织方式
2. **斜杠命令** - 高效的内容插入
3. **深度集成** - 与飞书生态无缝衔接
4. **用户体验** - 流畅的交互设计

我们的实现应该优先保证 **P0 核心功能** 的完整性，再逐步扩展高级功能。
