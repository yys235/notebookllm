## 1. 概述

飞书文档是字节跳动旗下的一款企业级在线协作文档产品，采用现代化的块编辑器架构，支持多人实时协作编辑。其核心特点包括:

- **块结构设计**: 文档由多个Block组成，每个Block是内容的基本单元
- **富文本能力**: 支持完整的文本格式化和排版功能
- **协同编辑**: 基于OT算法实现多人实时协作
- **开放API**: 提供完整的文档操作接口
- **可扩展性**: 支持自定义块和小组件

## 2. 块编辑器架构

### 2.1 核心概念

飞书文档采用 **Blocks 块结构设计**，Block是文档内容的最小构建单元:

| 概念 | 说明 |
|------|------|
| **Block (块)** | 文档内容的基本单元，可以是文字、表格、图片等 |
| **block_id** | 每个Block的唯一标识符 |
| **层级结构** | 多个Block可形成树状层级结构 |
| **内容块** | 飞书文档中内容管理的基础单位 |

### 2.2 Block类型分类

飞书文档目前支持 **50+ 种Block类型**，主要分为以下几类:

#### 文本类型功能块

| Block Type | 说明 |
|------------|------|
| `Page` | 页面块，文档根节点 |
| `Text` | 普通文本段落 |
| `Heading1` ~ `Heading9` | 1-9级标题 |
| `Bullet` | 无序列表项 |
| `Ordered` | 有序列表项 |
| `Task` | 任务块 |
| `Todo` | 待办块 |

#### 容器类型功能块

| Block Type | 说明 |
|------------|------|
| `TableCell` | 表格单元格 |
| `GridColumn` | 栏布局容器 |
| `SyncBlock` | 同步块，支持跨文档同步 |

#### 媒体类型功能块

| Block Type | 说明 |
|------------|------|
| `Image` | 图片块 |
| `Video` | 视频块 |
| `File` | 文件块 |
| `Audio` | 音频块 |

#### 其他功能块

| Block Type | 说明 |
|------------|------|
| `Code` | 代码块 |
| `Quote` | 引用块 |
| `Divider` | 分割线 |
| `Table` | 表格 |
| `Callout` | 高亮块 |
| `Bookmark` | 书签/链接卡片 |

### 2.3 技术架构

```
┌─────────────────────────────────────────────────────────┐
│                    飞书文档架构                          │
├─────────────────────────────────────────────────────────┤
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐    │
│  │   DOM渲染   │  │ Canvas表格  │  │ Widget引擎  │    │
│  │  (主要内容) │  │  (电子表格) │  │ (多维表格)  │    │
│  └─────────────┘  └─────────────┘  └─────────────┘    │
├─────────────────────────────────────────────────────────┤
│                    Block 模型层                         │
│     ┌─────┬─────┬─────┬─────┬─────┬─────┐             │
│     │Page │Text │Image│Table│Code │ ... │             │
│     └─────┴─────┴─────┴─────┴─────┴─────┘             │
├─────────────────────────────────────────────────────────┤
│                    协同编辑层 (OT算法)                   │
├─────────────────────────────────────────────────────────┤
│                    数据持久化层                          │
└─────────────────────────────────────────────────────────┘
```

**技术栈说明**:
- 文档主体基于 **DOM** 渲染
- 表格组件使用自研 **Canvas** 绘制
- 多维表格参考 **Flutter** 实现基于Widget的渲染引擎

### 2.4 Block数据结构示例

```json
{
  "block_id": "doxcnPFfFk7JhA6JhNv4KbOfXzc",
  "block_type": 2,
  "text": {
    "elements": [
      {
        "text_run": {
          "content": "Hello World",
          "text_element_style": {
            "bold": true,
            "italic": false,
            "underline": false
          }
        }
      }
    ]
  }
```

## 3. 富文本格式

## 4. 段落样式

### 4.1 标题层级

飞书文档支持 **多级标题** (H1-H9):

| 标题级别 | Markdown语法 | 说明 |
|----------|-------------|------|
| H1 | `# 标题` | 一级标题 |
| H2 | `## 标题` | 二级标题 |
| H3 | `### 标题` | 三级标题 |
| ... | ... | ... |
| H9 | `######### 标题` | 九级标题 |

### 4.2 对齐方式

支持多种对齐方式:
- 左对齐
- 居中对齐
- 右对齐

### 4.3 缩进功能

缩进功能支持以下内容类型:
- 标题
- 正文段落
- 有序列表
- 无序列表
- 任务列表
- 图片
- 文件
- 表格
- 群聊

**操作方式**:
- **增加缩进**: `Tab` 键
- **减少缩进**: `Shift + Tab` 键

### 4.4 列表样式

#### 有序列表
- **创建方式**: 输入 `1.` + 空格
- **嵌套**: 使用 Tab 键增加缩进层级
- **折叠**: 多层嵌套列表支持折叠功能

#### 无序列表
- **创建方式**: 输入 `-` 或 `*` + 空格
- **嵌套**: 支持 Tab 键嵌套
- **折叠**: 多层嵌套支持折叠

#### 任务列表
- **创建方式**: 输入 `[]` + 空格
- **勾选状态**: 可勾选完成
- **同步**: 任务可同步到任务中心

## 5. 链接功能

### 5.1 超链接

飞书文档支持在文档中添加超链接，点击可跳转至对应网页。

**添加方式**:
1. 选中文本 → 点击工具栏链接按钮 → 输入URL
2. 直接粘贴URL自动识别

### 5.2 链接视图类型

插入网页链接时，支持 **四种展示视图**:

| 视图类型 | 说明 |
|----------|------|
| **链接视图** | 纯链接文本形式 |
| **标题视图** | 显示网页标题 |
| **卡片视图** | 卡片式展示，包含标题和摘要 |
| **预览视图** | 完整预览，包含图片和描述 |

### 5.3 锚点链接

可以在文档中获取任意内容的链接:
- 某个句子
- 某个段落
- 某个内容块

点击锚点链接可直接跳转到文档内对应位置。

### 5.4 双向链接

在文档中引用其他文档时，系统会自动建立文档间的 **双向链接关系**:
- 可查看当前文档引用了哪些文档
- 可查看哪些文档反向引用了当前文档

### 5.5 链接预览开发

开发者可配置链接预览功能:
- 在开发者后台创建应用
- 添加链接预览能力
- 配置域名回调
- 实现自定义URL展示

### 7.2 单元格操作

## 8. 代码块

### 8.1 基本功能

| 功能 | 说明 |
|------|------|
| **语言支持** | 支持 65-70+ 种编程语言 |
| **语法高亮** | 根据语言自动高亮 |
| **一键换行** | 代码自动换行展示 |
| **复制按钮** | 一键复制代码 |

### 8.2 支持的语言

主流编程语言包括:
- C、C++
- Java
- Python
- JavaScript、TypeScript
- Go
- Rust
- SQL
- HTML、CSS
- Shell/Bash
- 等 70+ 种语言

### 8.3 使用方式

1. **创建代码块**:
   - 输入 `/代码块` 选择
   - 使用 Markdown: \`\`\`语言名

2. **选择语言**:
   - 首次默认为 Plain Text
   - 点击可切换代码语言

3. **语言记忆**:
   - 系统记录最近使用的语言
   - 下次创建时自动应用

### 8.4 注意事项

> 飞书目前 **不支持自动识别语言**，必须手动指定语言类型才能正确高亮。

## 10. 分割线

### 10.1 功能说明

用于在文档中插入水平分割线，分隔不同章节或内容区域。

### 10.2 创建方式

- 输入 `/分割线` 选择
- 使用 Markdown: `---` 或 `***`

> - 建议确保减号前面有适当空格或独立成行

## 11. 协同编辑技术

### 11.1 OT算法概述

飞书云文档采用 **OT (Operational Transformation) 算法** 实现协同编辑:

| 特性 | 说明 |
|------|------|
| **原理** | 记录每个用户的操作并广播同步 |
| **转换** | 在其他用户端进行相应转换和应用 |
| **优势** | 解决并发编辑冲突，保证数据一致性 |
| **应用** | 多人实时协作编辑 |

### 11.2 OT vs CRDT

| 特性 | OT算法 | CRDT算法 |
|------|--------|----------|
| **冲突处理** | 需要操作转换 | 数据结构本身避免冲突 |
| **服务器依赖** | 需要中央服务器协调 | 不需要中央服务器 |
| **精度** | 高精度冲突处理 | 最终一致性 |
| **适用场景** | 在线文档协作 | 分布式系统 |

### 11.3 协同编辑核心要素

1. **操作记录**: 记录每个用户的编辑操作
2. **操作广播**: 将操作同步给其他用户
3. **冲突处理**: 处理并发编辑冲突
4. **版本控制**: 维护文档版本历史

## 12. 扩展能力

### 12.1 同步块

| 特性 | 说明 |

| 组件名称 | 功能描述 |

| **飞书快译** | 快速翻译功能 |
| **公众号排版器** | 公众号文章排版 |

### 12.3 开放API

飞书开放平台提供完整的文档API:

| API | 功能 |
|-----|------|

| `POST /docx/v1/documents/{id}/blocks` | 创建块 |

| `DELETE /docx/v1/documents/{id}/blocks` | 删除块 |

### 12.4 Docs Add-on
