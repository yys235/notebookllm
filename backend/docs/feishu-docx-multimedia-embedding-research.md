## 1. 概述

飞书文档是字节跳动旗下的在线协作文档产品，提供丰富的多媒体嵌入和扩展能力。本文档详细调研了飞书文档的多媒体与嵌入功能，为 NotebookLLM 项目提供技术参考。

### 1.1 核心特性

- **多媒体支持**: 视频、音频、图片、文件附件
- **可视化工具**: 思维导图、流程图、画板
- **开发者友好**: 代码块、公式编辑器、Mermaid 文本绘图
- **小组件生态**: 时间轴、倒计时、目录导航等
- **开放平台**: Docs Add-on 支持第三方集成开发

### 1.2 平台支持情况

| 功能 | 桌面端 | 网页版 | 移动端 |
|------|--------|--------|--------|
| 视频嵌入 | 支持 | 支持 | 部分支持 |
| 思维导图 | 支持 | 支持 | 仅查看 |
| 流程图 | 支持 | 支持 | 支持 |
| 代码块 | 支持 | 支持 | 支持 |
| 公式编辑 | 支持 | 支持 | 即将上线 |
| 第三方嵌入 | 支持 | 支持 | 部分支持 |

## 2. 视频嵌入

### 2.1 功能简介

飞书文档支持在文档中嵌入和播放多种视频平台的视频内容，无需额外点击跳转，提供更便捷的观看体验。

### 2.2 支持的视频平台

| 平台 | 支持状态 | 备注 |
|------|----------|------|
| 西瓜视频 | 支持 | 官方示例平台 |
| 抖音 | 支持 | 字节跳动生态 |
| 哔哩哔哩 (B站) | 支持 | 主流视频平台 |
| 优酷 | 支持 | 阿里旗下视频平台 |
| 爱奇艺 | 支持 | 主流视频平台 |
| YouTube | 未明确 | 可能受国内网络限制 |

### 2.3 嵌入方式

**方式一: 粘贴链接**
1. 打开目标视频，复制地址栏链接
2. 在文档中粘贴链接，系统自动识别并嵌入

**方式二: / 快速插入**
1. 在文档空白行输入 `/`
2. 选择"视频"或直接粘贴视频链接

**方式三: 工具栏插入**
1. 鼠标悬浮在空白行左侧
2. 点击 `+` 工具栏
3. 选择"图片/视频"选项

### 2.4 播放控制

- 内嵌播放器，支持在文档内直接播放
- 播放速度调节
- 音量控制
- 视频大小调整
- 全屏播放

### 2.5 妙记视频嵌入

飞书妙记 (会议录音转写) 视频可直接嵌入文档:

- 以预览视图形式展示
- 无需跳转即可在文档中直接播放
- 支持查看会议转写内容

### 2.6 官方文档

- [在文档中嵌入视频](https://www.feishu.cn/hc/zh-CN/articles/635939752168)
- [在文档中嵌入妙记视频](https://www.feishu.cn/hc/zh-CN/articles/979064987931)

## 4. 文件附件

### 4.1 功能简介

飞书文档支持插入多种格式的文件附件，并提供在线预览能力。

### 4.2 支持的文件格式

| 类型 | 格式 |
|------|------|
| 文档 | PDF, Word (.doc, .docx), PPT, Excel |
| 媒体 | 视频 (MP4, MOV 等), 音频 (MP3, WAV 等) |
| 图片 | PNG, JPG, GIF, SVG 等 |
| 其他 | 压缩包, 代码文件等 |

### 4.3 文件操作

**上传方式**
- 点击 `+` 工具栏选择"文件"
- 拖放文件到文档
- 从云盘选择文件

**预览功能**
- 支持在线预览 Office 文件
- PDF 文件直接预览
- 视频音频在线播放

**下载功能**
- 支持下载到本地
- 支持另存为副本

### 4.4 显示方式

- **文本视图**: 以文件名形式显示
- **卡片视图**: 以卡片形式展示文件信息
- **预览视图**: 直接在文档中预览文件内容

### 4.5 图标显示

- 根据文件类型自动显示对应图标
- 支持文件缩略图预览
- 显示文件大小、修改时间等元信息

### 4.6 官方文档

- [在文档中插入图片、视频和文件](https://www.feishu.cn/hc/zh-CN/articles/360033767993)

## 8. 公式/数学

### 8.1 功能简介

飞书文档内置公式编辑器，支持使用 LaTeX 语法编辑数学公式，并提供实时预览功能。

### 8.2 技术实现

- **公式引擎**: KaTeX
- **语法标准**: LaTeX
- **渲染方式**: 实时预览

### 8.3 支持的公式类型

- 基础数学符号
- 分数和根式
- 上下标
- 矩阵
- 求和、积分、极限
- 希腊字母
- 特殊符号
- 多行公式

### 8.4 插入方式

**方式一: / 快速插入**
```
在空白行输入 /gs 或 /eq
```

**方式二: 菜单插入**
- 点击"插入"菜单
- 选择"公式"

### 8.5 编辑体验

- **实时预览**: 编辑 LaTeX 代码时实时显示公式形态
- **语法提示**: 支持常用公式语法
- **快捷输入**: 支持常用符号快捷输入

### 8.6 示例

```latex
# 勾股定理
a^2 + b^2 = c^2

# 求和公式
\sum_{i=1}^{n} x_i

# 积分公式
\int_{a}^{b} f(x) dx

# 矩阵
\begin{pmatrix}
a & b \\
c & d
\end{pmatrix}
```

## 9. 时间线

### 9.1 功能简介

时间轴小组件用于在文档中图形化表达事件的发展进程，适合展示历史、里程碑、项目进度等内容。

### 9.2 适用场景

| 角色 | 场景 |
|------|------|
| 行政、市场、销售 | 展示公司、产品或部门发展历史 |
| 项目经理 | 展示项目里程碑和进度 |
| 产品经理 | 展示产品迭代历程 |
| HR | 展示公司大事件 |

### 9.3 核心功能

**节点编辑**
- 添加/删除时间节点
- 编辑节点标题
- 编辑节点描述
- 设置节点时间

**样式调整**
- 节点样式
- 连接线样式
- 颜色主题
- 布局方向

**视图切换**
- 水平时间轴
- 垂直时间轴

### 9.4 组件规范

根据飞书开放平台设计规范:
- **连接线**: 串联每一个时间节点
- **节点标签**: 分为圆点标签和图标标签
- **节点标题**: 可自定义设置

## 10. 小组件

### 10.1 功能简介

文档小组件是飞书文档推出的一套开放能力，支持企业 IT 人员、独立服务商和个人开发者按需拓展文档能力。

### 10.2 内置小组件列表

| 小组件 | 功能描述 | 快捷命令 |
|--------|----------|----------|
| **目录导航** | 自动生成文档目录 | `/ml` |
| **时间轴** | 图形化展示事件进程 | - |
| **倒计时** | 可视化呈现剩余时间 | `/djs` |
| **文本绘图** | 基于 Mermaid 语法的图表 | - |
| **批量设置格式** | 批量修改文本格式 | - |
| **文字排版助手** | 辅助文字排版 | - |
| **词条助手** | 管理和引用词条 | - |
| **飞书快译** | 文档翻译功能 | - |

### 10.3 倒计时小组件

**功能特点**
- 计算从当前时刻到预设结束时间的剩余时长
- 支持重复倒计时 (按天、周、月等)
- 可视化呈现时间流逝

**使用场景**
- 会议计时
- 头脑风暴
- 重要活动倒计时
- 项目截止日期提醒

**插入方式**
- `/djs` 快捷命令
- 工具栏选择"倒计时"

**注**: 移动端暂不支持此功能

### 10.4 文本绘图小组件 (Mermaid)

**功能简介**
基于 Mermaid 语法，用代码方式快速搭建复杂图形。

**支持的图表类型**
- 流程图 (Flowchart)
- 时序图 (Sequence Diagram)
- 甘特图 (Gantt Chart)
- 饼图 (Pie Chart)
- 类图 (Class Diagram)
- 状态图 (State Diagram)

**编辑功能**
- 内置多种图表模板
- 代码/图表视图切换
- 全屏编辑模式
- 主题颜色切换

**适用人群**
- 研发人员: 技术文档、架构说明
- 产品经理: PRD、功能说明
- 项目负责人: 项目管理文档

- [在文档中插入倒计时](https://www.feishu.cn/hc/zh-CN/articles/442582079971)

1. **插件系统**: 参考 Docs Add-on 设计开放 API
2. **小组件**: 提供小组件开发 SDK
