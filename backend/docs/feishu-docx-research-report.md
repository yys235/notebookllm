## 1. Slash命令系统

### 1.1 功能概述

飞书文档的 Slash 命令系统（`/` 快速插入）是一种高效的编辑方式，允许用户通过输入 `/` 快速插入各种内容类型。

### 1.2 触发方式

| 触发位置 | 操作 | 说明 |
|---------|------|------|
| 行首 | 输入 `/` | 在任意一行的行首输入 |
| 空格后 | 输入 `/` | 在空格后面输入 |
| 任意位置 | 输入 `/` | 弹出插入菜单 |

**注意**: 移动端暂不支持此功能。

### 1.3 核心特性

- **提高编辑效率**: 使用 `/` 快速插入，快速找到想添加的内容
- **支持模糊输入**: 输入模糊词（如英文单词、拼音首字母等）也可找到功能
- **键盘导航**: 可通过键盘上下键选择，回车确认

### 1.4 支持的内容类型

#### 基础内容

| 类型 | 缩写/快捷方式 | 说明 |
|------|-------------|------|
| 标题 | `/h` 或 `/bt` | 快速插入标题 |
| 有序列表 | `1.` 或 `1、` | 自动转为有序列表 |
| 无序列表 | `-` 或 `*` | 自动转为无序列表 |
| 任务列表 | `/rw` | 创建待办任务 |
| 代码块 | `/dm` | 支持70+编程语言语法高亮 |
| 引用 | `/yy` | 插入引用块 |
| 分割线 | `/fg` | 插入水平分割线 |

#### 富媒体内容

| 类型 | 说明 |
|------|------|
| 图片 | 支持本地上传、截图粘贴、URL插入 |
| 视频 | 支持嵌入视频 |
| 表格 | 插入表格 |
| 电子表格 | `/dz` 快速插入 |
| 思维导图 | 插入思维导图 |
| 流程图/UML图 | 插入流程图 |
| 画板 | 插入画板 |

#### 协作内容

| 类型 | 说明 |
|------|------|
| 投票 | 插入投票组件 |
| 信息收集 | 插入表单 |
| 任务 | 创建和管理任务 |
| OKR | 插入OKR目标 |
| 日程卡片 | 插入日程 |
| 倒计时 | 插入倒计时 |

#### 嵌入内容

| 类型 | 说明 |
|------|------|
| 网页链接 | 嵌入网页 |
| 订阅号文章 | 嵌入飞书订阅号文章 |
| Figma | 嵌入Figma设计稿 |
| 墨刀 | 嵌入墨刀原型 |
| Canva可画 | 嵌入Canva设计 |
| 码上掘金/CodePen | 嵌入代码演示 |
| 飞书问卷 | 嵌入问卷 |
| 地图 | 嵌入地图 |

### 1.5 快捷键支持

| 功能 | Windows | Mac |
|------|---------|-----|
| 代码块 | `Ctrl + Alt + C` | `Command + Option + C` |
| 任务列表 | `Ctrl + Alt + T` | `Command + Option + T` |
| 分割线 | `Ctrl + Alt + S` | `Command + Option + S` |
| 查看快捷键列表 | `Ctrl + /` | `Command + /` |
| 内容块内换行 | `Shift + Enter` | `Shift + Enter` |

## 2. 模板系统

### 2.1 模板库概述

飞书基于云文档的各项功能，结合实际使用场景，预置了丰富精美的云文档模板。

### 2.2 模板分类

#### 按职能分工

| 分类 | 适用场景 |
|------|---------|
| 产品 | 产品需求文档、产品路线图、竞品分析 |
| 研发 | 技术方案、API文档、代码审查 |
| 设计 | 设计规范、设计评审、用户体验报告 |
| 运营 | 活动策划、运营报告、数据分析 |
| 市场 | 市场调研、营销方案、品牌策划 |
| 销售 | 销售计划、客户管理、合同模板 |
| 人事 | 招聘流程、员工手册、绩效考核 |
| 行政 | 会议记录、资产管理、行政通知 |

#### 按场景分类

| 分类 | 说明 |
|------|------|
| 最新 | 最新上线的模板 |
| AI专区 | AI相关的模板 |
| 问卷专区 | 问卷相关的模板 |
| 我的模板 | 用户保存的自定义模板 |
| 与我共享 | 他人分享的模板 |

### 2.3 自定义模板

#### 创建自定义模板

1. 将现有云文档转换为模板
2. 方便重复使用内容
3. 支持分享给团队成员

#### 局部模板

- 将文档中的部分内容保存为局部模板
- 可在其他文档中随时复用
- 提高文档创作效率

#### 管理局部模板

- 进入: 云文档主页 → 模板库 → 我的模板
- 操作: 分享、编辑、删除

### 2.4 模板使用流程

1. **进入模板库**
   - 云文档主页右上角点击"模板库"
   - 或点击"新建"后选择云文档类型进入

2. **浏览/搜索模板**
   - 浏览预置模板
   - 关键词搜索
   - 按类型筛选

3. **使用模板**
   - 点击"预览"查看内容
   - 点击"使用"创建文档
   - 复制/分享模板链接

## 3. 大纲/目录

### 3.1 自动生成目录

#### 基本功能

- 添加章节标题后**自动生成目录**
- 目录固定展示在正文左侧
- 点击目录节点可快速跳转至对应正文
- 支持折叠目录

#### 快速添加目录

输入 `# 目录` 并按下回车键，飞书会自动扫描文档中的标题，生成一个**动态目录**，目录会随着编辑自动更新。

### 3.2 目录导航小组件

#### 功能特点

- 将目录插入文档正文
- **筛选特定等级标题**
- **隐藏特定标题**
- 让文档结构更清晰

#### 使用场景

- 复杂文档结构管理
- 长文档快速导航
- 特定章节快速定位

### 3.3 标题层级

#### Markdown语法支持

| 层级 | 语法 | 说明 |
|------|------|------|
| 一级标题 | `# 标题` | 最高层级 |
| 二级标题 | `## 标题` | 子章节 |
| 三级标题 | `### 标题` | 子子章节 |
| 四级标题 | `#### 标题` | 更细分 |
| 五级标题 | `##### 标题` | 最细分 |

### 3.4 锚点跳转

- 目录条目自动添加**锚点跳转链接**
- 支持页面内章节跳转
- 可获取并使用锚点链接

## 6. 版本历史

### 6.1 功能概述

文档提供强大的版本管理功能，帮助用户轻松找回历史版本，当内容被修改时，系统会**自动保留历史版本**。

### 6.2 核心功能

| 功能 | 说明 |
|------|------|
| 版本保存 | 系统自动保留历史版本 |
| 修改记录 | 记录修改人、修改时间和修改细节 |
| 版本恢复 | 一键恢复至任意历史版本 |
| 版本下载 | 支持下载历史版本 |

### 6.3 版本管理功能

#### 文档版本管理

- 无需创建多个副本
- 根据需要随时保存新版本
- 版本链接永久有效，方便分享

#### 文件版本更新

- 上传本地文件到云文档后可更新
- 更新文件时链接保持不变
- 支持删除不需要的版本

#### 表格特殊功能

- 支持查看单元格级别的修改记录
- 可追溯具体的修改内容

### 6.4 操作流程

1. 打开文档
2. 点击右上角图标
3. 在菜单栏中点击"历史记录"
4. 历史记录按时间倒序排列
5. 选择版本进行查看或恢复

### 6.5 权限说明

- 只有拥有文档**编辑权限**的用户才可以查看及还原历史记录
- 给文档数据提供安全的保护

## 7. 导出功能

### 7.1 支持的导出格式

#### 文档导出

| 格式 | 说明 |
|------|------|
| Word (.docx) | Microsoft Word 格式 |
| PDF | 便携文档格式 |
| PNG (部分支持) | 图片格式 |

#### 表格导出

| 格式 | 说明 |
|------|------|
| Excel (.xlsx) | Microsoft Excel 格式 |
| CSV | 逗号分隔值 |

### 7.2 导出方法

#### 单个文档导出

1. 打开需要导出的飞书文档
2. 点击文档右上角的 **"..."** 菜单
3. 选择 **"导出为"**
4. 选择 PDF 或 Word 格式
5. 等待导出完成

#### 批量导出

- 可批量选择多个文档
- 导出后保持原有目录结构
- 文档中的图片、视频也会一并下载

### 7.3 第三方导出工具

| 工具名称 | 支持格式 | 特点 |
|---------|---------|------|
| feishu-doc-export | Markdown、docx、PDF | 支持 Windows/Mac/Linux，一键导出知识库 |
| feishu2md | Markdown | 专门将飞书文档导出为 Markdown |
| 飞书转存专家 | PDF、Word、HTML、Markdown | 浏览器扩展，保留样式 |

### 7.4 注意事项

| 项目 | 说明 |
|------|------|
| Word 格式 | 导出后可能会损失部分原有格式 |
| PDF 格式 | 保留格式效果较好 |
| 权限限制 | 可能受文档/文件夹/企业级别的权限限制 |
| 存储空间 | 存储容量满时无法创建新文档 |

## 8. 打印功能

### 8.1 打印方式

#### 方式一: 云打印功能

1. 在飞书客户端搜索"云打印"
2. 拖拽或上传要打印的文件
3. 设置参数（颜色、方向、纸张尺寸）
4. 点击确定，文件进入待打印状态

#### 方式二: 桌面端直接打印

- 进入飞书桌面端 → 工作台 → 智睦云打印
- 需先联系管理员授权
- 安装打印客户端后可使用本地打印

#### 方式三: 快捷键打印

| 平台 | 快捷键 |
|------|--------|
| Windows | `Ctrl + P` |
| Mac | `Command + P` |

### 8.2 打印设置

#### 页面设置

- 在打印预览页顶部导航点击【页面设置】
- 可调整页边距

#### 页面宽度设置

| 选项 | 说明 |
|------|------|
| 默认 | 标准宽度 |
| 较宽 | 更宽的正文区域 |
| 全宽 | 正文区域占据最大宽度 |

#### 页眉页脚

- 通过【插入】→【页眉和页脚】→ 页脚进行设置
- 可添加页码

### 8.3 打印权限

1. 云文档页面右上方
2. 点击 **分享 > 权限设置**
3. 找到"谁可以创建副本、打印和下载"
4. 按需修改权限设置

### 8.4 限制说明

| 功能 | 支持情况 |
|------|----------|
| 文档打印 | 支持 |
| 文档页边距设置 | 支持（打印预览页） |
| 文档页眉页脚 | 支持 |
| 表格边距/页眉页脚 | **暂不支持** |
| 手机直接打印 | **暂不支持** |

## 10. 总结与建议

### 10.1 功能对比总结

| 功能模块 | 完善度 | 特色功能 |
|---------|--------|---------|
| Slash命令系统 | ★★★★★ | 模糊输入、拼音支持、丰富内容类型 |
| 模板系统 | ★★★★★ | 多维度分类、自定义模板、局部模板 |
| 大纲/目录 | ★★★★☆ | 自动生成、小组件、锚点跳转 |
| 查找替换 | ★★★★☆ | 全局搜索、正则支持 |
| 字数统计 | ★★★☆☆ | 基础统计、互动统计 |
| 版本历史 | ★★★★★ | 自动保存、单元格级追溯 |
| 导出功能 | ★★★★☆ | 多格式支持、批量导出 |
| 打印功能 | ★★★☆☆ | 云打印、权限控制 |
| 文档设置 | ★★★★☆ | 页宽、封面、安全设置 |

### 10.2 可借鉴的设计要点

#### Slash命令系统

1. **模糊匹配**: 支持拼音首字母、英文缩写等模糊输入
2. **分类展示**: 内容类型按功能分类展示
3. **键盘友好**: 完整的键盘导航支持

#### 模板系统

1. **多维度分类**: 按职能、场景、类型等多维度组织
2. **局部模板**: 支持保存部分内容为模板
3. **模板分享**: 支持团队内模板共享

#### 版本历史

1. **自动保存**: 无需手动操作，系统自动保留
2. **细粒度追溯**: 表格支持单元格级别追溯
3. **权限控制**: 只有编辑权限才能查看/恢复

### 10.3 NotebookLLM 项目建议

基于飞书文档的调研，建议 NotebookLLM 项目在实现高级编辑功能时考虑以下要点:

1. **Slash命令系统**
   - 实现模糊匹配和拼音支持
   - 支持丰富的内容类型插入
   - 提供完整的键盘导航

2. **模板系统**
   - 建立模板分类体系
   - 支持自定义模板和局部模板
   - 实现模板分享机制

3. **版本历史**
   - 自动保存历史版本
   - 提供版本对比功能
   - 细粒度的修改记录

4. **导出功能**
   - 支持多种导出格式（PDF、Word、Markdown）
   - 保持格式一致性
   - 支持批量导出
