## 1. 工具栏设计

### 1.1 工具栏布局

飞书文档提供多种工具栏辅助文档内容编辑：

#### 主工具栏（顶部固定）
- **位置**: 文档顶部固定区域
- **功能分组**:
  - 文件操作区（新建、保存、导出）
  - 撤销/重做区
  - 文本格式区（字体、字号、加粗、斜体、下划线）
  - 段落格式区（对齐、缩进、列表）
  - 插入区（图片、表格、视频、代码块等）
  - 协作区（分享、评论、历史）

#### 浮动工具栏（选中文本后出现）
- **触发条件**: 选中文本内容后自动出现
- **位置**: 选中文本上方悬浮显示
- **功能**:
  - 设置多级标题（H1-H3）
  - 调整缩进与对齐方式
  - 设置粗体、斜体
  - 添加超链接
  - 文字颜色和高亮
  - 快速评论

### 1.2 图标设计规范

- **风格**: 简洁线性图标（Line Icons）
- **尺寸**: 16px/20px/24px 三档
- **颜色**: 默认灰色(#5F6368)，激活状态蓝色(#3370FF)
- **交互反馈**: Hover 时显示浅灰背景，提供工具提示（Tooltip）

### 1.3 内容块工具栏

- **触发方式**: 鼠标悬停在内容块左侧
- **显示**: 左侧浮现图标，表示可操作的内容块
- **功能**:
  - 拖拽排序
  - 添加评论
  - 删除块
  - 复制块
  - 转换为其他块类型

## 2. 侧边栏设计

### 2.1 大纲/目录侧边栏

#### 功能特性
- **自动生成**: 添加章节标题后，目录自动生成
- **位置**: 固定展示在正文左侧
- **交互**:
  - 点击目录节点快速跳转至对应正文
  - 支持折叠/展开多级目录
  - 长文档时可折叠整个目录面板

#### 目录导航小组件
- 可将目录插入文档正文
- 支持筛选特定等级标题
- 支持隐藏特定标题
- 适用于长文档管理

### 2.2 评论侧边栏

#### 功能特性
- **入口**: 右侧边栏顶部显示评论图标和数量
- **交互**:
  - 点击展开评论侧边栏
  - 点击跳转至首条评论
  - 支持精准评论（选中文字、图片或视频）

#### 评论功能
- **普通评论**: 所有有权限者可见
- **私有评论**: 仅文档所有者、管理者、发布者可见
- **图片标记**: 评论图片时可添加框选标记
- **@提及**: 通过@提及相关人员参与讨论
- **翻译功能**: 支持评论内容翻译

### 2.3 历史/版本管理侧边栏

#### 版本记录功能
- **自动保留**: 系统自动保留历史版本
- **记录内容**: 修改人、修改时间、修改细节
- **版本管理**: 无需创建多个副本，高效完成版本管理
- **分享功能**: 版本链接可分享给他人
- **恢复功能**: 可随时还原至任意历史版本

#### 多维表格历史
- 保留 **180天内** 的全部历史记录
- 记录数据表配置和数据的增、删、改操作

### 2.4 AI侧边栏

- **入口**: 右上角AI图标
- **功能**:
  - 与AI对话
  - 输入问题或点击推荐问题
  - 支持@功能

## 3. 快捷键系统

### 3.1 完整快捷键列表

#### 标题格式

| 功能 | Windows | Mac |
|------|---------|-----|
| 一级标题 | Ctrl + Alt + 1 | Cmd + Option + 1 |
| 二级标题 | Ctrl + Alt + 2 | Cmd + Option + 2 |
| 三级标题 | Ctrl + Alt + 3 | Cmd + Option + 3 |
| 普通文本 | Ctrl + Alt + 0 | Cmd + Option + 0 |

#### 文本格式

| 功能 | Windows | Mac |
|------|---------|-----|
| 加粗 | Ctrl + B | Cmd + B |
| 斜体 | Ctrl + I | Cmd + I |
| 下划线 | Ctrl + U | Cmd + U |
| 删除线 | Ctrl + Shift + X | Cmd + Shift + X |

#### 撤销与重做

| 功能 | Windows | Mac |
|------|---------|-----|
| 撤销 | Ctrl + Z | Cmd + Z |
| 重做 | Ctrl + Y | Cmd + Y 或 Cmd + Shift + Z |

#### 内容块

| 功能 | Windows | Mac |
|------|---------|-----|
| 代码块 | Ctrl + Alt + C | Cmd + Option + C |
| 任务列表 | Ctrl + Alt + T | Cmd + Option + T |
| 分割线 | Ctrl + Alt + S | Cmd + Option + S |
| 内容块内换行 | Shift + Enter | Shift + Enter |

#### 搜索功能

| 功能 | Windows | Mac |
|------|---------|-----|
| 飞书全局搜索 | Ctrl + K | Cmd + K |
| 页面内搜索 | Ctrl + F | Cmd + F |

#### 快捷键面板

| 功能 | Windows | Mac |
|------|---------|-----|
| 打开快捷键面板 | Ctrl + / | Cmd + / |

### 3.2 Markdown语法快捷输入

飞书文档深度支持Markdown语法，实现高效写作：

| 效果 | 语法 |
|------|------|
| 加粗 | `**文本**` |
| 斜体 | `*文本*` |
| 删除线 | `~~文本~~` |
| 一级标题 | `# ` + 空格 |
| 二级标题 | `## ` + 空格 |
| 三级标题 | `### ` + 空格 |
| 无序列表 | `- ` 或 `* ` + 空格 |
| 有序列表 | `1.` + 空格 |
| 任务列表 | `[]` 或 `[x]` |
| 代码块 | ` ``` ` |
| 引用 | `> ` + 空格 |
| 上标 | `^` |
| 下标 | `_` |

### 3.3 快捷键提示设计

- **位置**: 每个工具的浮窗上显示对应快捷键
- **格式**: 灰色小字，如 `(Ctrl+B)`
- **交互**: 鼠标悬停时显示完整提示

## 5. 拖拽交互

### 5.1 内容块拖拽排序

- **触发**: 拖动内容块左侧的拖拽手柄
- **视觉反馈**: 拖拽时显示半透明预览和插入位置指示线
- **动画**: 平滑过渡动画
- **支持类型**: 标题、段落、列表项、任务等所有内容块

### 5.2 图片拖拽

#### 交互手势
- **新文档版本**: 放大镜手势（支持放大预览）
- **旧文档版本**: 抓手手势（支持拖拽移动）

#### 拖拽操作
- 拖拽图片调整位置
- 拖拽图片边角调整大小
- 支持从本地直接拖拽图片上传

### 5.3 文件拖拽上传

- **上传区域**: 明确的拖拽触发区域
- **视觉提示**: 拖拽文件进入时高亮显示上传区
- **支持格式**: 图片、PDF、PPT、Excel、音视频等
- **进度反馈**: 上传进度条显示

### 5.4 拖拽式布局

- 组件自由拖拽
- 支持缩放操作
- 支持复制操作
- 支持全屏展示

## 6. 选中交互

### 6.1 文本选中效果

- **选中文本**: 浅蓝色背景高亮
- **选中反馈**: 即时响应，无明显延迟
- **跨块选择**: 支持跨多个内容块选择

### 6.2 选中后操作菜单（浮动工具栏）

选中文本后自动出现浮动工具栏，提供快捷操作：

```
┌──────────────────────────────────┐
│ [B] [I] [U] [颜色] [高亮] [链接] │
└──────────────────────────────────┘
```

**功能列表**:
- **B** - 加粗
- **I** - 斜体
- **U** - 下划线
- **颜色** - 文字颜色选择器
- **高亮** - 背景高亮颜色
- **链接** - 添加超链接
- **评论** - 添加评论
- **更多** - 展开更多格式选项

### 6.3 图片选中交互

- **选中状态**: 显示蓝色边框和调整手柄
- **尺寸调整**: 拖拽四角或边中点调整大小
- **对齐操作**: 快速设置图片对齐方式

## 7. 光标设计

### 7.1 基础光标样式

- **文本光标**: 竖线光标 `|`，黑色
- **闪烁频率**: 约 500ms 间隔
- **光标高度**: 根据当前行字体大小自适应

### 7.2 协作者光标

#### 多人协作光标设计
- **颜色区分**: 每位协作者分配不同颜色
- **光标标签**: 显示协作者姓名
- **位置标识**: 实时显示协作者编辑位置
- **防冲突**: 通过颜色区分避免输入冲突

#### 视觉设计
```
┌──────────────────────────────┐
│  这是一段示例文本│张三        │
│                  ↑           │
│              彩色光标+姓名标签 │
└──────────────────────────────┘
```

### 7.3 光标位置保存

- **自动保存**: 实时保存光标位置
- **恢复机制**: 重新打开文档时恢复到上次编辑位置
- **协作同步**: 所有协作者实时看到彼此光标位置

## 8. 响应式设计

### 8.1 设备适配策略

| 设备类型 | 分辨率建议 | 适配策略 |
|---------|-----------|---------|
| 手机端 | 1080 x 1920 | 简化界面，底部工具栏 |

| 折叠屏 | 1600 x 1600 | 全屏适配 |
| 桌面端 | 1920 x 1080+ | 完整功能界面 |

### 8.2 自适应框架

飞书搭建了完整的**界面布局自适应框架**：
- 灵活适配不同屏幕尺寸
- 适配不同交互方式
- 适配不同使用场景
- 确保各类设备上的一致体验

### 8.3 移动端特性

#### 横屏模式
- **自动切换**: 关闭竖排方向锁定时自动切换
- **手动切换**: 系统设置控制
- **优化布局**: 横屏时展示更多内容

#### 触控优化
- 增大点击区域
- 手势操作支持（滑动、捏合缩放）
- 底部工具栏设计

### 8.4 鸿蒙系统适配

- 支持"一次开发，多端部署"
- 移动端和电脑端功能同步
- 键鼠操作更便捷
- 多窗并行效率翻倍

## 9. 主题支持

### 9.1 深色模式

#### 支持版本
- 飞书客户端 V7.4 及以上版本

#### 设置方式
- **手动切换**: 在设置中手动开启/关闭
- **跟随系统**: 移动端可设置跟随系统自动切换
  - iOS 13+ 支持深色模式
  - Android 10+ 支持深色主题

#### 深色模式设计规范
- **背景色**: 深灰 (#1F1F1F) 而非纯黑
- **文字色**: 浅灰 (#E3E3E3) 而非纯白
- **强调色**: 保持品牌蓝色
- **对比度**: 确保文字可读性

### 9.2 主题色

- 桌面端支持 **5种主题色** 切换
- 主题色应用于图标、按钮、链接等强调元素

### 9.3 网页端深色模式

网页版可通过以下方式实现深色模式：
- 安装 Stylish 浏览器插件
- 应用飞书文档深色模式主题

## 12. 总结与建议

### 12.1 飞书文档设计亮点

1. **极简主义**: 界面简洁，让用户专注于内容创作
2. **Markdown优先**: 支持丰富的快捷语法，高效写作
3. **协作体验**: 多人实时光标、评论、版本管理
4. **内容块理念**: 一切皆块，灵活组合
5. **渐进式复杂度**: 基础功能易用，高级功能可发现

### 12.2 NotebookLLM项目应用建议

#### 高优先级
1. 实现浮动工具栏（选中即编辑）
2. 支持 Markdown 快捷输入
3. 添加大纲/目录侧边栏
4. 实现深色模式

#### 中优先级
1. 内容块拖拽排序
2. 评论系统
3. 版本历史
4. 快捷键系统

#### 低优先级
1. 多人协作光标
2. 自定义主题色
3. 移动端完整适配
