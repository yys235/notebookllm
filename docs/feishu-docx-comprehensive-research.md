## 1. 编辑器核心功能

### 1.1 块编辑器架构

#### 1.1.1 Block 结构设计

飞书文档采用 **Blocks 块结构设计**，Block 是文档内容的最小构建单元。

**Block 类型分类（50+ 种）：**

| 类型 | 包含内容 |
|------|----------|
| **文本类型** | 文本(Text)、标题(Heading1-9)、有序列表(OrderedList)、无序列表(UnorderedList)、任务列表(Task)、代码块(Code)、引用块(Quote) |
| **容器类型** | 页面(Page)、表格(Table)、网格(Grid)、分栏(Column) |
| **媒体类型** | 图片(Image)、文件(File)、视频(Video)、音频(Audio) |
| **嵌入类型** | Iframe、Divider、同步块(SyncBlock) |
| **智能类型** | 思维导图(Mindmap)、流程图(Diagram)、公式(Formula)、投票(Vote) |

**技术实现：**
- 文档主体：基于 **DOM 渲染**
- 表格：使用自研 **Canvas 绘制**
- 多维表格：参考 Flutter 实现，基于 Widget 的渲染引擎

#### 1.1.2 Block 数据结构示例

```json
{
  "block_type": "text",
  "text": {
    "elements": [
      {
        "text_run": {
          "content": "Hello World",
          "text_element_style": {
            "bold": true,
            "italic": false,
            "underline": false,
            "strikethrough": false,
            "inline_code": false,
            "text_color": 1,
            "background_color": 1
          }
        }
      }
    ],
    "style": {
      "align": 1,
      "header": true,
      "header_level": 1
    }
  }
}
```

### 1.2 富文本格式

#### 1.2.1 文字格式化

| 功能 | 快捷键 (Windows) | 快捷键 (Mac) | Markdown 语法 |
|------|------------------|--------------|---------------|
| 加粗 | `Ctrl + B` | `Cmd + B` | `**文字**` |
| 斜体 | `Ctrl + I` | `Cmd + I` | `*文字*` |
| 下划线 | `Ctrl + U` | `Cmd + U` | - |
| 删除线 | `Ctrl + Shift + X` | `Cmd + Shift + X` | `~~文字~~` |
| 行内代码 | `Ctrl + E` | `Cmd + E` | `` `代码` `` |
| 链接 | `Ctrl + K` | `Cmd + K` | `[文字](URL)` |

**颜色设置：**
- 文字颜色：支持预设颜色和自定义颜色
- 背景颜色：支持高亮背景色设置
- 字号范围：12px - 72px

#### 1.2.2 浮动工具栏

选中文本后自动浮现，提供快捷操作：
- **基础格式**：加粗、斜体、下划线、删除线
- **颜色设置**：文字颜色、背景色
- **链接插入**：快速添加超链接
- **评论功能**：对选中内容添加评论

### 1.3 段落样式

#### 1.3.1 标题层级

| 层级 | 快捷键 | Markdown |
|------|--------|----------|
| H1 | `Ctrl + Alt + 1` | `# 标题` |
| H2 | `Ctrl + Alt + 2` | `## 标题` |
| H3 | `Ctrl + Alt + 3` | `### 标题` |
| H4-H9 | `Ctrl + Alt + 4-9` | `#### 标题` |

**标题特性：**
- 支持 H1 到 H9 共 9 个层级
- 标题自动显示在左侧大纲中
- 支持标题折叠功能

#### 1.3.2 对齐与缩进

**对齐方式：**
- 左对齐（默认）
- 居中对齐
- 右对齐
- 两端对齐

**缩进功能：**
- 支持增加/减少缩进
- 有序列表和无序列表支持嵌套（最多 9 级）
- 任务列表支持嵌套

#### 1.3.3 列表样式

| 类型 | 快捷键 | Markdown |
|------|--------|----------|
| 有序列表 | `Ctrl + Shift + 7` | `1. 内容` |
| 无序列表 | `Ctrl + Shift + 8` | `- 内容` 或 `* 内容` |
| 任务列表 | `Ctrl + Shift + 9` | `- [ ] 任务` |

**列表特性：**
- 支持 Tab 键增加缩进
- 支持 Shift + Tab 减少缩进
- 任务列表支持勾选状态
- 支持列表折叠

## 2. 高级编辑功能

### 2.1 Slash 命令系统

#### 2.1.1 触发方式

- 在**行首**或**空格后**输入 `/` 即可弹出插入菜单
- 支持 `Ctrl + /` (Windows) 或 `Cmd + /` (Mac) 查看快捷键

#### 2.1.2 命令分类

| 分类 | 内容示例 |
|------|----------|
| **基础内容** | 标题、列表、代码块、引用、分割线 |
| **富媒体内容** | 图片、视频、表格、思维导图、流程图 |
| **协作内容** | 投票、任务、OKR、公告 |
| **嵌入内容** | Figma、CodePen、地图、问卷 |

#### 2.1.3 模糊搜索特性

- 支持**拼音首字母**搜索：`/bt` → 标题
- 支持**英文缩写**：`/img` → 图片
- 支持**中英文混合**搜索

#### 2.1.4 常用快捷命令

| 命令 | 功能 | 拼音快捷 |
|------|------|----------|
| `/标题` | 插入标题 | `/bt` |
| `/有序列表` | 有序列表 | `/yxlb` |
| `/无序列表` | 无序列表 | `/wxlb` |
| `/任务` | 任务列表 | `/rw` |
| `/代码块` | 代码块 | `/dmk` |
| `/表格` | 表格 | `/bg` |
| `/图片` | 图片 | `/tp` |
| `/分割线` | 分割线 | `/fgx` |
| `/引用` | 引用块 | `/yy` |

- 设计：设计规范、设计评审
- 运营：活动方案、运营报告
- 市场：市场调研、竞品报告

- 人事：招聘流程、员工手册

**按场景分类：**
- AI 专区：AI 辅助模板

#### 2.2.2 自定义模板

- 将云文档**转换为模板**重复使用
- **局部模板**：保存文档部分内容为模板
- 模板管理：模板库 → 我的模板

#### 2.4.1 基本功能

- 最近修改时间

### 2.6 版本历史

#### 2.6.1 功能特性

- **自动保存**：系统自动保留历史版本
- **修改记录**：记录修改人、修改时间、修改细节
- **版本恢复**：一键恢复至任意历史版本
- **细粒度追溯**：表格支持单元格级别修改记录

- 只有**编辑权限**才能查看/还原历史记录

## 5. 功能优先级建议

### 5.1 高优先级（P0）

| 功能 | 原因 | 实现难度 |
|------|------|----------|
| 浮动工具栏 | 核心编辑体验 | 中 |
| Slash 命令 | 效率提升明显 | 中 |
| Markdown 支持 | 用户习惯 | 低 |
| 大纲/目录 | 导航必备 | 中 |
| 深色模式 | 用户体验 | 低 |

### 5.2 中优先级（P1）

| 功能 | 原因 | 实现难度 |
|------|------|----------|
| 内容块拖拽 | 交互体验 | 中 |
| 评论系统 | 协作基础 | 高 |
| 版本历史 | 安全保障 | 高 |
| 代码高亮 | 开发者友好 | 低 |
| 图片上传 | 常用功能 | 中 |

### 5.3 低优先级（P2）

| 功能 | 原因 | 实现难度 |
|------|------|----------|
| 多人协作光标 | 实时协作 | 高 |
| 思维导图 | 高级功能 | 高 |
| 流程图 | 高级功能 | 高 |
| 第三方嵌入 | 扩展能力 | 中 |
| 自定义主题 | 个性化 | 低 |
