- 操作系统: Windows 11
- 浏览器: Chrome 122
- 分辨率: 1920x1080

#### 复现步骤
1. 打开水平分割的 Split Panes Demo
2. 按住分割线
3. 缓慢向右拖动

#### 预期结果
面板大小应连续、平滑地跟随鼠标移动
