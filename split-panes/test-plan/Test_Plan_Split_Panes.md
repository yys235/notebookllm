| 项目 | 内容 |
|------|------|
| 组件名称 | Split Panes |

| 创建日期 | 2026-03-02 |

---

## 1. 测试范围

### 1.1 功能测试
- 水平/垂直分割正常显示
- 拖拽调整大小功能
- 最小/最大尺寸限制
- 嵌套分割功能
- 键盘操作

### 1.2 边界测试
- 快速拖拽
- 超出边界拖拽
- 嵌套多层分割
- 窗口 resize

### 1.3 可访问性测试
- 键盘导航
- ARIA 属性

---

## 2. 测试策略

### 2.1 测试方法
- **手工测试**: 主要用于交互功能和视觉验证
- **自动化测试**: 使用 Playwright 进行端到端测试
- **可访问性测试**: 使用 axe-core 进行 A11y 检查

### 2.2 测试优先级
- **P0**: 核心功能（分割显示、拖拽调整）
- **P1**: 重要功能（尺寸限制、嵌套分割）
- **P2**: 辅助功能（键盘操作、可访问性）

---

## 3. 测试环境要求

### 3.1 浏览器
- Chrome (最新版)
- Firefox (最新版)

### 3.2 设备
- 桌面端: Windows, macOS, Linux

### 3.3 测试工具
- Playwright (自动化测试)

---

## 4. 缺陷严重级别定义

| 级别 | 定义 | 示例 |
|------|------|------|
| 严重 | 功能无法使用，导致测试无法继续 | 分割面板完全不显示 |
| 高 | 核心功能失效，但可绕过 | 拖拽功能完全失效 |
| 中 | 功能部分失效，有替代方案 | 边界限制不准确 |
| 低 | UI 问题，不影响功能 | 样式轻微错位 |
